Form Đăng Nhập

| Thành phần | Ý nghĩa | | -------------------------------------- | ---------------------------------------------------------------------- | | `form class="form-horizontal"` | Tạo **form dạng ngang**, dùng hệ thống lưới để canh lề. | | `div class="form-group"` | Một nhóm điều khiển (label + input), có margin dưới. | | `label class="control-label col-sm-2"` | Label được canh ngang, chiếm **2 cột** (trong 12). | | `div class="col-sm-4"` | Phần chứa `input`, chiếm **4 cột**. | | `input class="form-control"` | Định dạng ô nhập liệu theo Bootstrap (bo tròn, padding đẹp, viền nhẹ). |
